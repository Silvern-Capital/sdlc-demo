# REQ-042: Reject telemetry samples with a timestamp too far in the future

Requirement id: REQ-042
Component: src/telemetry/ingest.py
Priority: Medium

## Statement

The ingest service must reject any telemetry sample whose timestamp is more
than 24 hours after the current time. A rejected sample must not be stored.
The rejection reason must mention "future".

## Acceptance criteria

1. A sample timestamped 25 hours in the future is rejected.
2. A sample timestamped 23 hours in the future is accepted.
3. The rejection reason contains the word "future".
4. All existing tests keep passing.
5. A new automated test covers criteria 1 to 3 and names REQ-042.

## Notes for the implementer

- validate_sample() already takes an injectable "now" for testing.
- Do not change the public function names.
